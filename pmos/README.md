# postmarketOS packages

- `install-sdcard.sh /dev/sdX`: builds an image and writes a bootable card. See
  [docs/en/install.md](../docs/en/install.md) ([français](../docs/fr/install.md)).
- `sync.sh <pmaports>`: copies the two packages into `pmaports/device/testing/`, after refreshing the
  files whose source lives elsewhere in the repository.
- Package contents, kernel patches and configuration: [docs/en/development.md](../docs/en/development.md)
  ([français](../docs/fr/development.md)).
